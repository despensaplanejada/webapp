## 🚀 Como colocar o seu RA passo a passo

Se você nunca usou o GitHub pelo terminal, siga este roteiro simples para registrar seu nome e RA:

### 1. Clonar o projeto (Apenas na primeira vez)
Abra o terminal (PowerShell, Prompt ou Terminal do VS Code) na pasta onde deseja salvar o trabalho e digite:
```bash
git clone https://github.com
```
*(Lembre-se de trocar o link acima pelo link real do nosso repositório!)*

### 2. Atualizar o seu código local (Faça SEMPRE antes de mexer)
Para garantir que você não vai apagar o RA de um colega que enviou antes de você, entre na pasta do projeto pelo terminal e baixe as atualizações:
```bash
cd NOME-DO-REPOSITORIO
git pull
```

### 3. Editar o arquivo
1. Abra a pasta do projeto no seu editor (como o **VS Code**).
2. Abra o arquivo `README.md`.
3. Vá até a seção **"👥 Integrantes e RAs"**, apague o texto de exemplo de uma das linhas e coloque o seu **Nome** e o seu **RA**.
4. Salve o arquivo (`Ctrl + S`).

### 4. Enviar a alteração para o GitHub
Volte ao terminal e execute estes três comandos em sequência para salvar na nuvem:

```bash
git add README.md
git commit -m "docs: adicionado RA do [Seu Nome]"
git push
```

---
💡 **Aviso importante:** Se o comando `git push` der algum erro de "Rejected" ou "Fetch first", significa que outro colega enviou o RA dele ao mesmo tempo que você. Para resolver, basta rodar `git pull` de novo e depois tentar o `git push`.
